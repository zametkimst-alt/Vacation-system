# Розміщення на Vercel

## Два способи розміщення: простий і складніший

### **Спосіб 1: Один клік (рекомендується)**

1. Перейди на https://github.com/new
2. Назви репозиторій `vacation-system` (або яке хочеш)
3. Завантаж усі файли з цього проекту (папка `src`, `package.json`, `vite.config.js`, `index.html` і `.gitignore`)
4. Натисни "Create repository"
5. Перейди на https://vercel.com
6. Натисни "Import Project"
7. Вибери свій GitHub репозиторій `vacation-system`
8. Vercel автоматично налаштує все й розмістить
9. Готово! Отримаєш посилання типу `vacation-system-xyz.vercel.app`

---

### **Спосіб 2: Локально через Git+CLI**

Якщо маєш терпління (trochyну складніше):

```bash
# 1. Встанови Vercel CLI
npm i -g vercel

# 2. Скопіюй усі файли з цього проекту в папку
cd vacation-system

# 3. Встанови залежності
npm install

# 4. Розмісти на Vercel
vercel

# Vercel спитає параметри, просто натискай Enter на усіх
```

Готово!

---

## Як редагувати список працівників

Відкрий файл `src/App.jsx` і знайди на початку:

```javascript
const DEFAULT_EMPLOYEES = [
  { name: "Петро", pin: "1111" },
  { name: "Марія", pin: "2222" },
  { name: "Іван", pin: "3333" },
];
```

Додай/видали/редагуй як потрібно, потім `git push` → Vercel автоматично перебудує сайт.

## Дані на цьому ПК

Поки дані зберігаються локально у браузері на кожному ПК (localStorage).
Якщо перейтися на інший пристрій — дані там не видно.

**Потім додамо Firebase** для синхронізації даних между всіма.
