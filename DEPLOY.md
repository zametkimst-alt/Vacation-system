# Платформа для управління заявками

## Архітектура

Цей проект побудований як **модульна платформа**:

```
/src
  /core            — ядро платформи (авторизація, зберігання, переводи)
  /modules         — модулі процесів (кожен в окремій папці)
    /vacationRequests  — модуль заявок на відпустку (перший приклад)
  App.jsx          — головна точка входу
```

Кожен модуль може працювати незалежно й легко додаватися/видалятися.

---

## Розміщення на Vercel (один клік)

1. Перейди на https://github.com/new
2. Назви репозиторій `vacation-system`
3. Завантаж все з цього проекту (папки `src`, `public`, файли `package.json`, `vite.config.js`, `index.html`, `.gitignore`)
4. Натисни "Create repository"
5. Перейди на https://vercel.com → "Import Project"
6. Вибери свій GitHub репозиторій
7. Vercel автоматично розмістить → готово! 🎉

Посилання виду: `vacation-system-xyz.vercel.app`

## Як додавати нові модулі

1. Створи папку `/src/modules/myModule/`
2. Додай структуру:
   ```
   myModule/
     index.js       — експорт модуля
     logic.js       — бізнес-логіка
     components.jsx — React компоненти
     types.js       — константи й типи
   ```
3. Експортуй компоненти `EmployeePanel` і `AdminPanel` з `index.js`
4. Додай модуль в `/src/core/moduleRegistry.js`
